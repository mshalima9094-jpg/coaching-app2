কোচিং ক্যাপ — অ্যাপ ব্যবহারবিধি
=============================

এই সংস্করণে অ্যাপের নাম ও হোম-স্ক্রিন আইকন পরিবর্তন করা হয়েছে।

১) ZIP ফাইলটি Extract/Unzip করুন।
২) index.html Chrome-এ খুললে অ্যাপ ব্যবহার করা যাবে।
৩) স্থায়ী ইনস্টলযোগ্য অ্যাপ হিসেবে চালাতে পুরো ফোল্ডারটি HTTPS হোস্টিংয়ে আপলোড করুন।
৪) Chrome-এ লিংক খুলে মেনু থেকে “Install app” বা “Add to Home screen” নির্বাচন করুন।
৫) পুরোনো ইনস্টল করা অ্যাপের আইকন বদলাতে হলে আগে পুরোনো শর্টকাট/ইনস্টলেশন সরিয়ে নতুন লিংক খুলে আবার Install করুন।
৬) অ্যাপের ডেটা ব্রাউজারে সংরক্ষিত থাকে। Settings থেকে নিয়মিত Backup ফাইল সেভ করে নিরাপদ স্থানে রাখুন।

ফাইলসমূহ: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png।
